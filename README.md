## About This Project
This repository contains Java programs demonstrating the fundamental concepts of Object-Oriented Programming (OOP). It covers classes and objects, encapsulation, inheritance, polymorphism, and abstraction.

## Topics Covered

1. **Classes and Objects** – Creating classes, objects, constructors, and methods.
2. **Encapsulation** – Data hiding using private fields and controlled access.
3. **Inheritance** – Code reusability using the extends keyword.
4. **Polymorphism** – Method overloading and method overriding.
5. **Abstraction** – Using abstract classes and methods.
